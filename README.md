# YT Studio

Локальный софт для YouTube: вставляешь сценарий → он сам находит видео/картинки, озвучивает,
накладывает музыку, субтитры, плашки, переходы и звуки → получаешь готовый mp4 (16:9 или Shorts 9:16).
Плохие моменты правятся в редакторе и ролик пересобирается.

## Установка

1. **Python 3.10+** — https://www.python.org/downloads/ (при установке поставь галочку *Add Python to PATH*).
2. **FFmpeg** — на Windows в терминале: `winget install Gyan.FFmpeg`, на Mac: `brew install ffmpeg`.
3. Скачай этот репозиторий (Code → Download ZIP) и распакуй.

## Запуск

- **Windows:** двойной клик по `run.bat`
- **Mac/Linux:** `./run.sh`

При первом запуске сам поставит зависимости. Откроется браузер на `http://127.0.0.1:8777`
(если порт занят — возьмёт следующий свободный). Другой порт: `run.bat 9000`.

## Как работать

1. **Настройки и API** — вставь ключи (все необязательные):
   Pexels, Pixabay (стоковые видео/фото), Google AI Studio (генерация картинок Nano Banana),
   Suno (музыка), ElevenLabs (голос). Wikimedia Commons и голос Edge TTS работают без ключей.
2. **Референсы** — загрузи пример монтажа. Софт определит формат, темп склеек (длину кадра)
   и сделает пресет стиля. Отметь в пресете то, что видишь в референсе: субтитры, плашки, переходы, зум, SFX.
3. **Новый проект** → выбери референс → вкладка **Сценарий** → вставь сценарий → **⚡ Сделать ролик**.
4. **Редактор** — поменять/обрезать/выключить кадр, найти другой на стоках, загрузить свой файл,
   поправить текст → **Пересобрать ролик**.
5. **Музыка** — свой трек или генерация в Suno. Режим «фон» (тихо, приглушается под голос)
   или «песня» (громко, ролик подгоняется под длину трека).
6. **YouTube** — название, описание, теги и промпты для превью — с кнопками «копировать».

Формат сценария — во вкладке «Формат сценария» внутри софта (там же кнопка «скопировать промпт для Claude»).

## Где что лежит

- `data/` — проекты, референсы, ключи (`settings.json`). Эта папка **не попадает в GitHub**.
- `data/sfx/` — положи сюда свои звуки (mp3/wav), они будут случайно ставиться на смену сцен.
  Если папка пустая — используется встроенный свуш.
- Готовый ролик: `data/projects/<id>/<Название>.mp4` или кнопка «Скачать» в софте.

## Голоса

- **Edge TTS** — бесплатно, онлайн, хорошее качество. Если сервис Microsoft не ответил,
  на Windows автоматически используется локальный голос.
- **Локальный голос Windows** — офлайн, попроще.
- **ElevenLabs** — по ключу.

## Устройство

`app/server.py` — сервер (FastAPI), `app/engine/` — монтаж (FFmpeg), поиск медиа, голос, Suno,
анализ референсов, `app/static/` — интерфейс.

## Ролик из файла задачи (без браузера)

1. Положи задачу `.md` (пример: `tasks/пример_задачи.md`).
2. Перетащи её на **`СДЕЛАТЬ_РОЛИК.bat`** (можно вместе с видео-референсом) — пойдут шаги по очереди:
   разбор → озвучка → видео/картинки → музыка (Suno) → сборка.
3. Готовый ролик: `data/projects/<id>/<название>.mp4`, проект виден и в браузере.

Строки-настройки в задаче: `PROJECT:` `CHANNEL:` `FORMAT: 16:9|9:16` `VOICE: edge|local|elevenlabs|нет`
`VOICE_NAME:` `REFERENCE:` (имя референса) `MUSIC:` (промпт для Suno) `MUSIC_MODE: фон|песня`.
Дальше — обычный сценарий (TITLE/DESCRIPTION/TAGS/THUMB и сцены `##`, `>`, текст).

Свою музыку — во вкладку проекта «🎵 Музыка». Свои звуки переходов (свуши) — в папку `data/sfx/`.
В браузере то же самое: кнопка «📄 Из файла задачи» на странице проектов.

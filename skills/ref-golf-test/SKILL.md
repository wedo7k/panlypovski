# «гольф тест» — как монтировать

- **Сценарий:** хук-парадокс (чемпион/известный факт → «а за этим стоял неизвестный человек»), потом хронология главами, финал-мораль одной фразой. 20–26 мин, ровный темп.
- **Сцены:** 1–2 предложения, кадр 3.5 с, растворения 0.45 с, медленный зум. **Субтитров нет.**
- **Плашка `## …`** у каждой сцены: 1–3 слова капсом («MIZUNO IRONS», «THE PLAYER», «STRONGER LOFTS»).
- **Графика на 25 мин (примерно):**
  - CHAPTER ×5 (paper);
  - TIMELINE ×8 — одна точка-год с подписью: `TIMELINE: | 2004 — MIURA GIKEN`;
  - SPAN ×4: `SPAN: 1994 → 2011 | 17 YEARS`;
  - PERSON ×6 (роль | ИМЯ) для экспертов и бизнесменов; PROFILE ×5 для игроков;
  - SPLIT ×4, CARD ×3, CIRCLES ×3 (`CIRCLES: Cavity backs | Blades`), HEX ×1 (`HEX: MIURA | Titleist; Mizuno; PING`);
  - DATE ×3–4 («May 14 | 2025»), TITLE ×3 («A Name Earned»), ASK ×2 (отдельной сценой);
  - PILL ×3 (`PILL: 300 • sets sold out`), HIGHLIGHT ×2, COUNTER ×1, LINE ×1, TABLE ×1 (итоги турнира), QUOTE ×2.
- **`>` запросы:** конкретные — кузница, ковка металла, гольф-айроны крупно, японский замок Himeji, турнирные лужайки, архивные фото игроков по именам (Wikimedia).
- **Музыка:** тихий эмбиент/пиано без бита, Am, 60 BPM, под голосом.

## Проверено на ролике LA Gear (проект 6f4b27e8b3) — обязательно

- **Ни один кадр не стоит дольше 4 с без плашки.** Шот длиннее 4 с режь на куски по ≤3.6 с, в каждый кусок — **своё новое фото/видео**.
  Одна и та же картинка, на которой меняется только текст графики 6–8 с подряд, — брак. Фото не повторять ближе 12 кадров.
- **Только по теме.** Нельзя: мультики, игры, 18+, «милые» картинки, политика (митинги), реклама, говорящие головы, рисунки не по теме.
  YouTube-клипы почти всегда мусор — бери Wikimedia короткими запросами 1–3 слова (имя человека, бренд, место, предмет:
  «Kareem Abdul-Jabbar», «Foot Locker», «New York Stock Exchange», «Reebok Freestyle», «roller skates»), 10 кандидатов на запрос,
  смотри листом глазами, отбирай, раскладывай по диапазонам сцен.
- **Сравнения верные:** в CIRCLES/COMPARE/SPLIT фото каждой стороны про ту сторону (Reebok — кроссовок Reebok, не случайный).
- **Реальные люди — реальные фото** (Майкл Джексон, игроки): именем на Wikimedia, не похожий человек.
- **Нет хорошего фото — не ИИ, а инфографика в стиле референса** (`TITLE` / `KICKER` / `QUOTE` / `FACT` / `COUNTER` / `RING` …)
  с фоном из безопасного пула фото этой же темы; текст — кусок фразы сцены ≤9 слов, без обрывков и повторов.
- **Вертикальные фото** не кропаются: софт сам кладёт их целиком в светлую рамку по центру на тёмном фоне со свечением.
- **Люди и события — боковая плашка `LABEL:`** (слева/справа по очереди): `LABEL: KAREEM ABDUL-JABBAR`, `LABEL: PEPSI · $10 MILLION`,
  `LABEL: CHAPTER 11 · 1998` — на каждую сцену, где впервые звучит человек, компания, издание или событие с датой.
- **Цифры — графикой:** COUNTER / RING / CHART / LINE / COMPARE на каждую весомую цифру (продажи, доля рынка, убытки).
- **Порядок работы:** сначала исправить ВСЕ кадры (листы `check/`, раскадровка), потом один рендер (он ~40 мин), потом
  раскадровка готового ролика `fps=1/20,tile=10x7` и точечная проверка подозрительных мест.

## Люди в кадре — ЛИЦО этого человека (урок LA Gear: Karl Malone)

- Сцена с плашкой человека (`LABEL:/LOWER:/NAME:/PERSON:` с именем) — в кадре под плашкой **его лицо**, узнаваемо.
  Брак: «KARL MALONE» поверх пальм Лос-Анджелеса, «PAULA ABDUL» поверх города. Хорошо сделано: Michael Jackson
  (студийный портрет), Hakeem, Kareem 1975, Malone в форме Jazz №32, Gretzky с кубком.
- Плашка ложится на **k-й кадр сцены** (k-я плашка → k-й не-графический кадр). Значит фото человека ставь первым
  не-графическим кадром сцены. Если имя звучит в конце длинной сцены, а первым идёт другой кадр — убери/отключи
  соседний кадр, чтобы человек с плашкой стоял на имени (≤4 с не обязательно — с плашкой можно дольше).
- **Где искать:** поиск софта (`sources.wikimedia`) по именам находит мало. Ищи прямо в Commons API:
  `https://commons.wikimedia.org/w/api.php?action=query&list=search&srsearch=<Имя>&srnamespace=6&srlimit=10&format=json`
  (requests с User-Agent; urllib падает на SSL). Выбирай файл по имени («Joe Montana Super Bowl 50.jpg»,
  «Paula Abdul 2007.jpg», «Roy E. Disney.jpg»), качай `https://commons.wikimedia.org/wiki/Special:FilePath/<Файл>`.
  Однофамильцы — не годятся (Ernest Williams / Robert Greenberg LA Gear на Commons нет — тогда оставь тему, не чужое лицо).
- **Проверка глазами до рендера:** лист «плашка → первые 2 кадра сцены» по всем сценам с именами; после рендера —
  кадр в момент, когда имя звучит (Whisper по аудио готового ролика → ffmpeg -ss → смотри).
